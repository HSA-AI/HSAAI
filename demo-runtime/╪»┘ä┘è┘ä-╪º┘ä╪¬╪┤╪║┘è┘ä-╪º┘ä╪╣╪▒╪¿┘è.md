# دليل تشغيل بيئة العرض — HSAAI (عربي)

## نظرة سريعة
هذا الدليل يشغّل منصة HSAAI كاملة للعرض التوضيحي على جهاز واحد **بدون Docker** — ثلاث عمليات خفيفة بدل 56 حاوية:

| العملية | المنفذ | الوظيفة |
|---------|--------|---------|
| mock-keycloak | 9080 | مزوّد هوية OIDC تجريبي (PKCE + RS256) |
| backend + shim | 8080 | خلفية FastAPI كاملة + عقد المصادقة والبوابة |
| Next.js web | 3000 | واجهة HSAAI العربية (RTL) |

## المتطلبات
- Node.js 18+ (اختُبر على 24)
- Python 3.12+ مع الحزم:
  ```bash
  pip install -r services/backend_core/requirements.txt
  ```
- حزم الواجهة:
  ```bash
  cd apps/web && npm install
  ```

## التشغيل (3 خطوات)

```bash
# 1) زرع بيانات العرض العربية (مرة واحدة بعد كل قاعدة جديدة)
python3 demo-runtime/seed_demo.py

# 2) إقلاع كل الخدمات
bash demo-runtime/start.sh

# 3) افتح المتصفح
http://127.0.0.1:3000
```

اضغط **«تسجيل الدخول عبر Keycloak»** → تظهر صفحة هوية العرض (حساب مدير النظام مُعبّأ مسبقًا) → اضغط **«تسجيل الدخول»** → تُوجَّه إلى لوحة HSAAI مباشرة.

## الإيقاف
```bash
bash demo-runtime/stop.sh
```

## بيانات الدخول التجريبية
| الحقل | القيمة |
|-------|--------|
| المستخدم | مدير النظام (demo) |
| الأدوار | hsaai_admin, ai_user, ai_admin, audit_viewer |
| المستأجر | hsa-enterprise |
| مساحة العمل | hq-main |

> هذه بيانات عرض افتراضية في `scripts/mock-keycloak.js` — ليست بيانات حقيقية ولا تصلح للإنتاج.

## استكشاف الأخطاء
| المشكلة | الحل |
|---------|------|
| الصفحة تظهر 404 على `/v1/keycloak/config` | تأكد أن mock-keycloak يعمل: `curl http://127.0.0.1:9080/health` |
| «chrome-error» بعد زر الدخول | أعد تشغيل الخلفية — تحقق من `demo-runtime/logs/backend.log` |
| جداول المعرفة فارغة | شغّل `python3 demo-runtime/seed_demo.py` ثم أعد تحميل الصفحة |
| المحادثة لا ترد | راجع `demo-runtime/logs/backend.log` — البوابة الافتراضية تتطلب جلسة صالحة |

## أسئلة المحادثة المقترحة للعرض
- «ما سياسة الإجازات السنوية؟»
- «لخص لي هذا التقرير التنفيذي وحدد أهم المخاطر والتوصيات»
- «ما سياسة العمل المرن؟»

كل إجابة تعرض المحتوى مع المصدر المؤسسي المُوثّق — كما هو مصمّم في «الردود الذكية» داخل المنصة.

## ملاحظة معمارية
بيئة Docker الكاملة (docker-compose، 56 خدمة) لم تُمس — هذا الدليل للمسار الخفيف فقط، ويناسب العروض والأجهزة المحدودة الموارد (يعمل بذاكرة أقل من 2GB).
