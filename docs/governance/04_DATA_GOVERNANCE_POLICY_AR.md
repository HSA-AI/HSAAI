# سياسة حوكمة البيانات لمنصة HSAAI

## 1.0 تصنيف البيانات
| التصنيف | الوصف | سياسة الاستخدام |
|---|---|---|
| عامة داخلية | معلومات متاحة لجميع الموظفين | يمكن فهرستها بعد اعتماد الإدارة المالكة |
| داخلية مقيدة | معلومات خاصة بإدارة محددة | تفهرس داخل Workspace محدد |
| سرية | بيانات مالية أو تشغيلية حساسة | تتطلب موافقة مالك البيانات والأمن السيبراني |
| سرية للغاية | بيانات تنفيذية أو شخصية عالية الحساسية | لا تفهرس إلا بقرار حوكمي خاص |

## 1.1 ضوابط رفع الملفات
- لا يحق رفع الملفات إلا للمستخدمين المخولين.
- يجب تحديد مالك البيانات والتصنيف قبل الفهرسة.
- يجب منع فهرسة الملفات الشخصية أو غير المعتمدة.
- يجب تسجيل كل عملية رفع وفهرسة في Audit Logs.

## 1.2 الاحتفاظ والحذف
- يتم تحديد مدة الاحتفاظ حسب نوع البيانات.
- يجب تمكين حذف الوثائق من الفهرس والمتجهات.
- يجب توثيق عمليات الحذف والاستعادة.

## 1.3 منع التسرب
- تفعيل Internal-Only للبيانات الحساسة.
- منع استخدام مزودي AI خارجيين دون موافقة.
- تشفير البيانات أثناء النقل والتخزين.
- مراقبة محاولات الوصول المرفوضة.
