# خطة إدارة التغيير والاعتماد المؤسسي

## 1.0 الهدف
ضمان أن يعتمد المستخدمون منصة HSAAI بطريقة صحيحة وآمنة، وأن تتحول المنصة إلى أداة عمل يومية ذات قيمة.

## 1.1 شرائح المستخدمين
| الشريحة | الاحتياج |
|---|---|
| الإدارة العليا | ملخصات ومؤشرات قرار |
| مدراء الإدارات | تقارير وسياسات ومعرفة إدارية |
| الموظفون | إجابات سريعة وسياسات وإرشادات |
| مسؤولو المعرفة | رفع الملفات ومراجعة المحتوى |
| مسؤولو النظام | إدارة الصلاحيات والتشغيل |

## 1.2 مواد التدريب
- دليل مستخدم مختصر.
- فيديو تعريفي قصير.
- أمثلة أسئلة جاهزة.
- سياسة الاستخدام المقبول.
- قناة ملاحظات ودعم.

## 1.3 خطة التواصل
| المرحلة | الرسالة |
|---|---|
| قبل Pilot | تعريف الغرض والنطاق |
| أثناء Pilot | تشجيع الاستخدام وجمع الملاحظات |
| بعد Pilot | نشر النتائج وخطة التوسع |

## 1.4 مقاومة التغيير
يجب معالجة التخوفات الشائعة: دقة الإجابات، الخصوصية، استبدال الوظائف، وصلاحيات الوصول، من خلال توعية واضحة بأن النظام مساعد داخلي محكوم وليس بديلاً عن الموظف.
