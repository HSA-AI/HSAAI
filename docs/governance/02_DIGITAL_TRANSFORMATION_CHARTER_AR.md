# ميثاق برنامج التحول الرقمي HSAAI

## 1.0 اسم البرنامج
**HSAAI — Hayel Saeed Anam Artificial Intelligence**

## 1.1 مالك البرنامج
مدير التحول الرقمي، بالتنسيق مع تقنية المعلومات، الأمن السيبراني، الموارد البشرية، المالية، والشؤون القانونية/الامتثال.

## 1.2 نطاق البرنامج
إنشاء منصة ذكاء اصطناعي داخلية تخدم الموظفين والإدارات، وتدعم البحث في الوثائق، التلخيص، التحليل، والوكلاء المتخصصين.

## 1.3 خارج النطاق في المرحلة الأولى
- اتخاذ قرارات قانونية أو مالية نهائية دون مراجعة بشرية.
- معالجة بيانات سرية للغاية دون اعتماد حوكمي مسبق.
- إتاحة المنصة خارج الشبكة الداخلية.
- ربط أنظمة إنتاج حساسة دون اختبار Staging.

## 1.4 أصحاب المصلحة
| الجهة | الدور |
|---|---|
| الإدارة العليا | اعتماد التوجه والتمويل |
| التحول الرقمي | قيادة البرنامج وقياس الأثر |
| تقنية المعلومات | التشغيل والتكامل |
| الأمن السيبراني | التقييم الأمني والاعتماد |
| الإدارات المالكة للبيانات | اعتماد الوثائق ومصادر المعرفة |
| المستخدمون الأوائل | تجربة النظام وتقديم الملاحظات |

## 1.5 مخرجات البرنامج
- منصة قابلة للتشغيل الداخلي.
- وثائق تشغيل وحوكمة.
- نموذج Pilot معتمد.
- مؤشرات أداء.
- تقرير اعتماد للتوسع.
