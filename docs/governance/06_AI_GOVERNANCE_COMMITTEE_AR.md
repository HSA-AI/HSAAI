# ميثاق لجنة حوكمة الذكاء الاصطناعي

## 1.0 الغرض
تضمن اللجنة أن استخدام HSAAI يتم وفق ضوابط الأمن، الخصوصية، الامتثال، والقيمة المؤسسية.

## 1.1 التشكيل المقترح
| العضو | المسؤولية |
|---|---|
| مدير التحول الرقمي | رئاسة اللجنة ومتابعة القيمة |
| مدير تقنية المعلومات | التشغيل والتكامل |
| الأمن السيبراني | التقييم والمخاطر |
| الموارد البشرية | سياسات الموظفين والاستخدام |
| المالية | ضوابط البيانات المالية |
| القانونية/الامتثال | الضوابط التنظيمية |
| مالك المنتج | إدارة خارطة الطريق |

## 1.2 صلاحيات اللجنة
- اعتماد حالات الاستخدام.
- اعتماد مصادر البيانات.
- مراجعة المخاطر.
- الموافقة على التوسع.
- مراجعة مؤشرات الأداء.
- إيقاف أي استخدام مخالف.

## 1.3 دورية الاجتماعات
- أسبوعياً أثناء Pilot.
- شهرياً بعد الإطلاق الرسمي.
- اجتماع استثنائي عند أي حادثة أمنية أو تشغيلية.
