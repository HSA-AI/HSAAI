# مصفوفة قرار النشر والتوسع

## 1.0 خيارات التشغيل
| الخيار | الوصف | مناسب لـ |
|---|---|---|
| Development | تشغيل محلي للمطورين | التطوير والاختبار السريع |
| Staging | بيئة شبه إنتاجية | Pilot والاختبارات |
| Production Internal | تشغيل داخلي رسمي | الاستخدام المؤسسي |
| Private Cloud | سحابة خاصة | توسع متعدد الشركات |

## 1.1 معايير الانتقال بين المراحل
| الانتقال | الشرط |
|---|---|
| Development إلى Staging | نجاح اختبارات الوحدة والتكامل |
| Staging إلى Pilot | اعتماد البيانات والصلاحيات |
| Pilot إلى Production | تحقيق مؤشرات النجاح وعدم وجود مخاطر حرجة |
| Production إلى توسع شامل | اعتماد الإدارة العليا ولجنة الحوكمة |
