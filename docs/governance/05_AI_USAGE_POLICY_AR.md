# سياسة استخدام الذكاء الاصطناعي في HSAAI

## 1.0 المبادئ
- HSAAI أداة مساعدة وليست بديلاً عن القرار البشري في المجالات الحساسة.
- يجب التحقق من الإجابات المهمة من مصادرها.
- يمنع رفع بيانات غير مصرح بها.
- يمنع استخدام النظام لإنتاج محتوى مخالف للسياسات الداخلية.

## 1.1 الاستخدامات المسموحة
| الاستخدام | الحالة |
|---|---|
| البحث في السياسات المعتمدة | مسموح |
| تلخيص التقارير الداخلية | مسموح حسب الصلاحيات |
| تحليل مستندات الإدارة | مسموح بعد اعتماد البيانات |
| دعم المستخدمين تقنياً | مسموح |

## 1.2 الاستخدامات المقيدة
| الاستخدام | الشرط |
|---|---|
| بيانات الموظفين | صلاحيات HR ومراجعة بشرية |
| بيانات مالية حساسة | موافقة الإدارة المالية |
| قرارات قانونية | مراجعة الشؤون القانونية |
| قرارات تنفيذية | اعتماد المسؤول المختص |

## 1.3 Human-in-the-Loop
في الحالات الحساسة يجب أن يعرض النظام تنبيهاً بأن الإجابة إرشادية وليست قراراً نهائياً، ويجب تحويلها إلى مسؤول مختص عند الحاجة.
