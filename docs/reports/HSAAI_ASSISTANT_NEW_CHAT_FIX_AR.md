# تقرير تعديل HSAAI Assistant

تم تثبيت التعديل المطلوب:

- عند النقر على زر **HSAAI Assistant** يتم فتح صفحة الشات الكاملة.
- يتم التوجيه إلى: `/chat?new=1`.
- صفحة الشات تقرأ الوسم `new=1` وتبدأ محادثة جديدة تلقائياً.
- إذا كان المستخدم موجوداً أصلاً داخل `/chat`، يتم إنشاء محادثة جديدة مباشرة بدون إعادة تحميل الصفحة.
- تم تحديث زر الدخول من الصفحة الرئيسية ليستخدم أيضاً `/chat?new=1`.

الملفات الأساسية التي تم التأكد منها:

- `apps/web/components/assistant/floating-assistant.tsx`
- `apps/web/app/chat/page.tsx`
- `apps/web/app/page.tsx`
