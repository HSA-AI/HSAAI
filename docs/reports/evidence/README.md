# Validation Evidence

This directory contains validation artifacts produced across multiple HSAAI
release stages.

Some artifacts, including rendered Helm manifests and release-status files,
were generated during the `v4.0.0-rc.2` validation period and are retained
unchanged for engineering traceability.

Their embedded release identifiers are historical evidence and must not be
rewritten to `v4.0.0`.

For the authoritative current software release status, refer to:

- `README.md`
- `docs/reports/CURRENT_RELEASE_STATUS.md`
- GitHub Release `v4.0.0`

The current published software release is:

**HSAAI v4.0.0 — Production Release**
