# HSAAI — حزمة التسليم الفني

الجهة المستفيدة: **هائل سعيد أنعم وشركاه**. الإصدار: **4.0.0-rc.1**.

هذه نسخة مصححة تستكمل المشروع المرفق مع المحافظة على جميع ملفاته وإصلاحاته الموجودة. حالتها **مرشح قبول فني**، ولم تُعتمد لتشغيل إنتاجي شامل.

ابدأ بهذه الملفات:

1. [تقرير الإصلاحات ونتائج التحقق](docs/release/DELIVERY_REPORT_AR.md).
2. [مطابقة محاور PDF وحالة كل محور](docs/release/REQUIREMENTS_TRACEABILITY_AR.md).
3. [دليل النشر والترقية والقبول](docs/release/DEPLOYMENT_ACCEPTANCE_AR.md).
4. [حالة الإصدار](docs/release/RELEASE_STATUS.json) و[سجل تغييرات الملفات](docs/release/SOURCE_CHANGES.json).

تتضمن الحزمة المصدر، إعدادات Docker/Kubernetes/Helm، ترحيلات قاعدة البيانات، الاختبارات، تعريفات الوكلاء، وثائق API المستخرجة من الشيفرة، والأدلة المتاحة. لا تحتوي على أسرار الشركة أو أوزان نماذج أو بيانات تدريب مؤسسية.

شرط التغطية الأصلي 80% باقٍ ولم يُخفّض. كما أن الحاويات الكاملة وPostgreSQL وSSO وGPU واختبارات الحمل والتعافي تحتاج تنفيذًا على بيئة اختبار الشركة. توجد بالمصفوفة بنود تتطلب تنفيذًا إضافيًا، خصوصًا برامج البحث والفوترة والبنية العالمية طويلة المدى في PDF.

التقارير الأقدم محفوظة للمرجعية؛ الحالة المعتمدة لهذا التسليم موضحة في docs/release عند اختلافها مع ادعاءات جاهزية سابقة. لا تُعد النماذج الأولية والقيَم التجريبية دليل أداء أو اعتماد إنتاج.
