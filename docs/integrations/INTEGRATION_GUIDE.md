# Integration Guide

Each connector must define:
- Connector key.
- System type.
- Authentication method.
- Base URL.
- Permission mapping.
- Data mapping.
- Retry policy.
- Test connection.
- Sync logs.
- Error handling.

Supported targets:
SAP S/4HANA, SAP SuccessFactors, Active Directory, Keycloak, Exchange/Outlook, SharePoint, Power BI, Jira, Service Desk, DMS, Data Warehouse, Oracle, PostgreSQL, REST APIs.

Use Mock Mode until enterprise credentials are available.
