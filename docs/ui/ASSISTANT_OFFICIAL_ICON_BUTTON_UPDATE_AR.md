# تحديث زر المساعد الذكي بالصورة الرسمية

تم تطبيق صورة المساعد الذكي الرسمية التي أرسلها المستخدم داخل نسخة المشروع بالكود.

## التعديلات
- نسخ الصورة إلى `apps/web/public/brand/hsaai-assistant-circle.png`.
- استخدام الصورة في زر المساعد في الصفحة الرئيسية.
- استخدام الصورة في زر المحادثة الجديدة في Sidebar.
- استخدام الصورة في التنقل السفلي للجوال.
- استخدام الصورة في بطاقات المساعد والزر العائم.

## المسار
كل الأزرار الرئيسية تفتح:

```text
/chat?new=1
```

## الحالة
تم الحفاظ على شعار HSAAI وألوان HSA الرسمية.
