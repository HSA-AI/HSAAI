# HSAAI Floating Assistant

## الهدف

تمت إضافة زر دائري صغير داخل واجهة منصة HSAAI ليظهر لجميع الموظفين في الشاشة الرئيسية وصفحات المنصة. يعمل الزر كمدخل سريع للمساعد الذكي الداخلي، بطريقة مشابهة لفكرة أيقونة الذكاء الاصطناعي داخل تطبيقات المحادثة، لكن بتصميم رسمي خاص بمنصة HSAAI وبيئة شركة هائل سعيد أنعم وشركاه.

## مكان الظهور

يظهر الزر في أسفل الشاشة، ويعمل على مستوى التطبيق بالكامل عبر ملف:

```text
frontend/app/layout.tsx
```

لذلك سيظهر في:

- الصفحة الرئيسية.
- لوحة التحكم.
- صفحة المحادثة.
- صفحة المعرفة.
- صفحة الحوكمة.
- صفحة التكاملات.
- صفحات الإدارة والإعدادات.

## الملفات المضافة

```text
frontend/components/assistant/floating-assistant.tsx
frontend/public/brand/hsaai-assistant-circle.svg
```

## الوظائف

- زر دائري ثابت باسم HSAAI Assistant.
- نافذة محادثة صغيرة قابلة للفتح والإغلاق.
- أسئلة جاهزة للموظفين.
- إرسال الطلبات إلى خدمة المحادثة الحالية عبر `sendChat`.
- احترام مساحة العمل الحالية `workspace_id`.
- رسالة أمان تؤكد أن البيئة داخلية وتخضع للصلاحيات والتدقيق.
- ألوان متوافقة مع هوية HSAAI: الأسود والأصفر.

## ملاحظات تشغيلية

يعتمد الزر على خدمة المحادثة الموجودة في:

```text
frontend/services/chat.service.ts
```

والتي ترسل الطلبات إلى:

```text
/v1/chat
```

يجب تشغيل API Gateway أو Backend المناسب حتى يتم الرد على الاستفسارات.
