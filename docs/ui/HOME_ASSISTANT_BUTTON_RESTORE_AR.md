# إصلاح ظهور زر المساعد الذكي في الشاشة الرئيسية

## سبب التعديل
بعد تطبيق هيكل Enterprise UX Architecture أصبحت الصفحة الرئيسية Assistant-first، لكن زر **المساعد الذكي** لم يكن ظاهرًا بما يكفي للمستخدم كما في التصميم المطلوب.

## ما تم تنفيذه
تم تعديل الملف:

```text
apps/web/app/page.tsx
```

وتمت إضافة ثلاث نقاط دخول واضحة للمساعد:

1. زر واضح في رأس الصفحة باسم **المساعد الذكي**.
2. زر كبير داخل Hero Section باسم **المساعد الذكي**.
3. زر عائم للجوال باسم **المساعد الذكي**.

## السلوك المطلوب
كل الأزرار تفتح:

```text
/chat?new=1
```

أي محادثة جديدة مع المساعد.

## الحفاظ على الهوية
تم الحفاظ على:

- شعار HSAAI الرسمي.
- ألوان HSA الرسمية: الأسود، الأصفر، الذهبي.
- RTL العربي.
- هيكل Enterprise UX المبسط.

## النتيجة
أصبح زر المساعد ظاهرًا بوضوح في الشاشة الرئيسية، ولا يعتمد المستخدم فقط على مربع السؤال أو القائمة الجانبية.
