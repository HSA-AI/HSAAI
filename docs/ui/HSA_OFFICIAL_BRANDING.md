# HSA Official Branding Layer

This release adds the official HSA visual identity layer to HSAAI.

## Added

- HSA logo asset: `frontend/public/brand/hsa-logo.jpg`
- Central frontend brand config: `frontend/lib/brand.ts`
- Branding components:
  - `BrandMark`
  - `OfficialBadge`
  - `BrandHero`
- HSA color tokens in Tailwind:
  - `hsa-yellow` — `#F0CF3A`
  - `hsa-black` — `#050505`
  - `hsa-gold` — `#C7A833`
  - `hsa-soft` — `#FFF7CC`
- Updated landing page, dashboard, sidebar, topbar, metadata and favicon.
- Backend branding endpoint:
  - `GET /branding/official`

## Official Positioning

The platform should be presented as:

> HSAAI — the internal enterprise AI operating system for Hayel Saeed Anam & Co.

## Compliance Note

Use of the company logo and visual identity should be approved by the authorized HSA brand/legal owner before production deployment.
