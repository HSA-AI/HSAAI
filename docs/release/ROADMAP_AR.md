# خارطة استكمال البرنامج

هذه خطة مقترحة، وليست نتائج منجزة أو وعدًا بمدة وتكلفة.

| الأفق | نطاق العمل | شرط الانتقال |
|---|---|---|
| بوابة القبول الحالية | إغلاق التغطية وفحوص الأمن، تشغيل الحاويات، PostgreSQL/SSO/RAG ومستأجران واستعادة | موافقة التقنية والأمن ومالك البيانات بأدلة فعلية |
| أول 90 يومًا بعد القبول | استخدام محدود لمستندات الشركة، تقييم بشري، دعم وتشغيل | دقة مصادر ونجاح تجربة مستخدمين واتفاق خدمة |
| 3–12 شهرًا | SAP/SharePoint/LDAP، حالة موزعة، تقييم نماذج | قبول مالكي الأنظمة واختبارات حمل وتعافٍ |
| السنة 1–3 | HA حقيقي وMLOps وتدريب محدد الأهداف | مقاييس أمن وجودة وتكلفة وموافقة الإدارة |
| السنة 3–5 | توسع إقليمي/اتحادي وEdge | إقامة بيانات وموارد وعقود وموافقات للمناطق المختارة |
| السنة 5–10 | بحث ومنظومة وكلاء متقدمة | نتائج قابلة لإعادة الإنتاج؛ قرار الإدارة النهائي وإيقاف التجارب غير المجدية |

لا تُستخدم الأرقام الثابتة أو مخرجات المحاكاة داخل الوحدات التجريبية كقياسات أداء حقيقية. تبقى هذه الوحدات خارج الاعتماد الإنتاجي حتى اجتياز معايير مستقلة.
