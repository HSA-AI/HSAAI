# خريطة مستودع HSAAI المؤسسي

|---|---|---|
| واجهة المستخدم | `apps/web` | صفحات ومكونات منصة HSAAI |

| الحزم المشتركة | `packages/common` | Config, Logging, Security, Schemas, Utils |
| التكاملات | `packages/integrations` | SAP, Windows Server, AD, File Server, SharePoint, BI, ITSM |
| الحوكمة | `packages/governance` | Policies, Audit, RBAC, Tenant Guard |
| البنية التحتية | `infrastructure/*` | Docker, Kubernetes, Helm, Keycloak, Monitoring |
| التوثيق | `docs/*` | Architecture, Operations, Integration, Security, Deliverables |
| الاختبارات | `tests/*` | Unit, Integration, Security, E2E, Load |
