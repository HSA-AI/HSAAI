# Admin Console Specification

## Modules

### Organizations

- Create/update organization.
- Configure internal-only policy.
- Configure storage quotas.
- Configure allowed models.

### Workspaces

- Create/update workspace.
- Assign users.
- Assign agents.
- Configure RAG collections and memory isolation.

### Users

- Invite user.
- Disable user.
- Reset MFA.
- Assign roles.

### Roles and permissions

- System Admin
- Organization Admin
- Workspace Admin
- Analyst
- Agent Operator
- Viewer

### Security

- View audit logs.
- Configure data retention.
- Configure upload restrictions.
- Configure model restrictions.
- Export compliance report.

### AI Operations

- Monitor token usage.
- Monitor model availability.
- Monitor RAG ingestion.
- Monitor agent runs.
- Stop suspicious workflow.
