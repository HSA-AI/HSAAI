# Vendor Security Policy (ISO 27001 A.5.19-A.5.23)

**Document ID:** ISMS-POL-011 | **Version:** 1.0.0 | **Date:** 2026-07-05

## 1. Vendor Assessment
- Security questionnaire before onboarding
- ISO 27001 or SOC 2 certification preferred
- Annual vendor risk assessment

## 2. Vendor Access
- Time-boxed access (max 8 hours for auditors)
- All vendor actions logged in audit trail
- MFA required for vendor access
- Vendor access reviewed quarterly

## 3. Data Sharing
- Data Processing Agreement (DPA) required
- Minimum necessary data shared
- PDPL/GDPR compliance verified

**Owner:** Procurement + CISO | **Review:** Annually
