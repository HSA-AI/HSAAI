# Remote Work Policy (ISO 27001 A.6.7)

**Document ID:** ISMS-POL-019 | **Version:** 1.0.0 | **Date:** 2026-07-05

## 1. Remote Access
- VPN required for internal services
- MFA required for all remote access
- Device must have endpoint protection
- Screen lock after 5 min idle

## 2. Data Handling
- No downloading sensitive data to personal devices
- Use HSAAI web interface (no local copies)
- Secure Wi-Fi only (no public networks)
- Privacy screen in public spaces

**Owner:** HR + CISO | **Review:** Annually
