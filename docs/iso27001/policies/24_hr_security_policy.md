# HR Security Policy (ISO 27001 A.6.1-A.6.6)

**Document ID:** ISMS-POL-024 | **Version:** 1.0.0 | **Date:** 2026-07-05

## 1. Pre-employment
- Background checks for all hires
- Security clearance for privileged roles
- NDA signed before access

## 2. During Employment
- Security awareness training: annual (100% completion)
- Role-based training for developers (OWASP, secure coding)
- Phishing simulation: quarterly

## 3. Termination
- Access revoked within 1 hour of termination
- Equipment returned within 24 hours
- Exit interview includes data return confirmation
- Audit log review for terminated user's last 30 days

## 4. Disciplinary Process
- Security violations: verbal warning → written → termination
- Serious violations (data theft, sabotage): immediate termination + legal action

**Owner:** HR Director + CISO | **Review:** Annually
